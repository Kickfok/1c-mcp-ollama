### find_report_queries

Поиск готовых запросов в отчетах конфигурации: образец, по которому составить свой запрос для run_query

Запросы собираются из основных схем компоновки отчетов конфигурации один раз за сеанс HTTP-сервиса: первый вызов на 1С:КА 2 занимает около 10 с, следующие - доли секунды. Просматриваются только отчеты, доступные пользователю.

| Параметр | Тип | Обязательный | По умолчанию | Описание |
|---|---|:---:|---|---|
| `keywords` | string | да |  | Слова для поиска через пробел: имя регистра, документа или справочника, тема отчета (например: ТоварыНаСкладах остатки) |
| `maxItems` | number |  | `1` | Сколько запросов вернуть, от 1 до 3 |

### validate_query

Проверка запроса 1С без чтения данных: синтаксис, имена таблиц и полей, права пользователя. Возвращает таблицы, колонки результата и параметры запроса с типами

Разбирает текст через СхемаЗапроса, данные не читает. Проверяет право Чтение пользователя на каждую таблицу, на таблицы во вложенных запросах условий и на объекты полей, прочитанных через точку (Т.Контрагент.ИНН).

| Параметр | Тип | Обязательный | По умолчанию | Описание |
|---|---|:---:|---|---|
| `query` | string | да |  | Текст запроса на языке запросов 1С (ВЫБРАТЬ ... ИЗ ...), параметры задаются как &Имя |

### run_query

Выполнение запроса 1С только на чтение с правами пользователя: возвращает колонки и строки результата. Язык запросов 1С: ВЫБРАТЬ [ПЕРВЫЕ n] Т.Поле КАК Имя ИЗ Справочник.Имя КАК Т [ГДЕ ...] [СГРУППИРОВАТЬ ПО ...] [УПОРЯДОЧИТЬ ПО ...]; агрегаты КОЛИЧЕСТВО(), СУММА(), МАКСИМУМ(), МИНИМУМ()

Те же проверки прав, что у validate_query. Ко всем запросам пакета добавляется РАЗРЕШЕННЫЕ, результат ограничен maxRows строками. Ограничения на уровне записей (RLS) пользователя не применяются: данные читаются сеансом публикации.

| Параметр | Тип | Обязательный | По умолчанию | Описание |
|---|---|:---:|---|---|
| `query` | string | да |  | Текст запроса на языке запросов 1С, проверенный через validate_query |
| `parameters` | object |  |  | Значения параметров &Имя, например {"НачалоПериода": "2026-01-01", "Склад": "Основной склад"}. Даты - ГГГГ-ММ-ДД, ссылку можно задать наименованием, кодом или номером документа |
| `maxRows` | number |  | `20` | Сколько строк результата вернуть, не больше 500 |
